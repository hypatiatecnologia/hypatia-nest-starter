# Hypatia Nest Starter v0.1.0

The first public release presents Hypatia's NestJS service baseline as a reusable GitHub template.

## Highlights

- Node.js 22 and NestJS 11 runtime contract
- API, worker, and messaging-off archetypes
- Prisma/PostgreSQL, Redis, and RabbitMQ adapters
- Correlation IDs, structured logging, health probes, graceful shutdown, validation, rate limiting, and redaction
- JWT and internal API-key examples with explicit deployment boundaries
- Atomic `create-service` scaffold and guarded local setup, covered by hermetic tests
- Pinned GitHub Actions, runtime dependency audit, gitleaks, Trivy, and container build gates
- Public documentation with generic topology and clear snapshot-update semantics

## Compatibility

This release requires Node.js 22. Docker with Compose is required for the complete local infrastructure flow. The repository remains private on npm and is distributed as a GitHub template.

## Before deployment

Replace all example credentials, define project-specific authorization and data policies, configure the reverse proxy and secret manager, and perform a dedicated threat and capacity review.

See `CHANGELOG.md` for the detailed hardening and behavior changes included in this snapshot.
